# YouTube Page Clone

A frontend project that replicates the layout and visual design of the YouTube homepage using **HTML and CSS**.

This project was created to practice building a real-world webpage layout from scratch and to improve understanding of HTML structure, CSS styling, positioning, and responsive webpage design.

## 🚀 Features

* 🎥 YouTube-inspired homepage layout
* 🔍 Search bar design
* 📱 Sidebar navigation
* 🎬 Video thumbnail layout
* 🖼️ Image-based video cards
* 📐 Structured webpage layout
* 🎨 Custom CSS styling
* 💻 Built from scratch using HTML and CSS

## 🛠️ Tech Stack

* HTML5
* CSS3

## 📂 Project Structure

```text
project/
│
├── image/              # Images and assets
├── search bar/         # Search bar components
├── sidebar/            # Sidebar components
├── styles/             # Additional styles
├── a.html              # HTML page
├── main.html           # Main webpage
├── youtube.html        # YouTube clone page
└── style.css           # Main stylesheet
```

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sahilja27/project.git
```

### 2. Navigate to the project

```bash
cd project
```

### 3. Run the project

Open `youtube.html` or `main.html` directly in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
